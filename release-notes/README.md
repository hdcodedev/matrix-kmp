# Release Notes

This directory holds user-facing release notes organized by version.

## Structure

Each release has its own directory named after the SemVer version:

```
release-notes/
  1.0.0/
    changes/
      123-add-feature-x.md
      456-fix-bug-y.md
```

Each markdown file under `changes/` describes a single change for that version.

These notes are included in the GitHub release when a production release is published.
